# 執筆ガイド：ゼロトラスト実践ノート（Zscaler ブログ）

`blogs/WRITING_RULES_COMMON.md` の共通ルールに加えて以下に従う。

- 読者：Zscaler を業務で触る初〜中級のネットワーク/セキュリティ担当者
- 出典：help.zscaler.com / trust.zscaler.com / zscaler.com の該当URL、必要に応じて NIST 等の公的文書
- 画像：Zscaler のロゴ・公式画像は使わない（image は付けない）

## zscaler-digest（月曜：週次アップデートまとめ）
- ナビ用タグ：`週次まとめ`
- 監視ツールが検出した直近7日の変更（ZIA / ZPA / ZDX / trust）を、
  「何が変わったか → 誰に影響するか → 運用者がやること」の順で整理する。
- trust.zscaler.com のメンテ・障害情報は、データセンター名・クラウド名・影響範囲を表にまとめる。
- 変化が少ない週は、変更点＋関連する基礎知識の解説で記事を成立させる。

## zscaler-topic（水・金：基礎・設計解説）
- ナビ用タグ：`基礎`
- 仕組み → 設計時の判断ポイント → よくある落とし穴 の流れで書く。
- 仕様の細部は公式ドキュメントで確認できたものだけを書く。
