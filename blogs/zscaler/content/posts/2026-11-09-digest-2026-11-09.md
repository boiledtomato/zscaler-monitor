11月2日〜9日に、監視ツールが検出した Zscaler 公式情報の変更をまとめます。
今週は、日本の拠点に関係する**大阪I（OSA1）のメンテナンス予告**と、**Client Connector の配信方法に関する不具合**が、運用者にとって特に重要です。
各項目は「何が変わったか → 誰に影響するか → 運用者がやること」の順で整理しています。

## 今週の要点

| 優先度 | 項目 | 対象 |
|---|---|---|
| 高 | 大阪I（OSA1）のハードウェアメンテナンス（11/19 0:00〜4:00 JST） | OSA1 を使う ZIA / ZPA 利用者 |
| 高 | Client Connector の段階配信が効かない不具合 | Authentication Service を使うテナント |
| 中 | Virtual Service Edge の通信要件の変更（2027年1月末から） | Virtual Service Edge を使う組織 |
| 中 | Agentic SecOps（旧 Avalor）の名称・ドメイン変更（11/15） | SecOps ポータルの利用者 |
| 情報 | 米国の一部拠点での性能低下（解消済み） | ダラス・マイアミ・アトランタ・ロサンゼルス経由の利用者 |
| 情報 | Linux カーネルの脆弱性への Zscaler の見解 | 自社で管理する Zscaler コンポーネントの OS |

## 1. 大阪I（OSA1）のメンテナンス予告

**何が変わるか**
大阪I（OSA1）のデータセンターで、ハードウェアメンテナンスが予定されています。

| 項目 | 内容 |
|---|---|
| 日時（JST） | 2026年11月19日 0:00〜4:00 |
| 日時（UTC） | 2026年11月18日 15:00〜19:00 |
| 対象クラウド | zscaler.net、zscalertwo.net、zscloud.net、zscalerthree.net、private.zscaler.com、zpatwo.net |
| 想定される影響 | 同じDC内の冗長機器に切り替わる。断続的な接続や、接続の張り直しが起こる可能性あり |

**誰に影響するか**
OSA1 に接続している ZIA・ZPA の利用者です。深夜帯ですが、夜間バッチや海外拠点との通信がある組織は注意が必要です。

**運用者がやること**
- 夜間に動く重要な処理がないかを確認し、必要なら時間をずらす
- メンテナンス中に問い合わせが来たときのために、ヘルプデスクへ事前に共有しておく
- 通信を特定のDCに固定している場合は、副系のDCへ切り替えられるかを確認する

なお、11/7 未明（HKT）には香港III（HKG3、zscloud.net）でも同様のハードウェアメンテナンスがあり、11/6 19:34 UTC に完了しています。

## 2. Client Connector の段階配信（Phased Rollout）が効かない不具合

**何が変わったか**
Authentication Service を使っているテナントで、Client Connector の更新を段階的に配信する設定（Phased Rollout）が正しく動かない不具合が見つかりました。App Store Group Policy で Phased Rollout を選んでも、**一斉配信（Mass Rollout）と同じように全端末へ配信されてしまいます**。

これを受けて、2026年11月6日の週から、該当テナントの「Add App Store Group Policy」画面では配信方法（Rollout Type）が表示されなくなり、自動的に一斉配信が適用されます。不具合の修正は**2027年2月**の予定です。

**誰に影響するか**
ユーザー認証に Authentication Service を使っているテナントです。

**運用者がやること**
- 自社テナントが Authentication Service を使っているかを確認する
- 「まず一部の端末に配って様子を見る」運用をしていた場合、その前提が使えない。新しいバージョンを配る前に、検証用のテナントや端末で動作を確かめるなど、別の手段で影響を抑える
- 修正が本番に出るまで、更新の配信タイミングを慎重に決める

## 3. Virtual Service Edge の通信要件の変更

**何が変わるか**
Virtual Service Edge（旧 VZEN）が、ポリシーや設定を取得する経路（コントロールプレーン）を変更します。今後は、各クラウドの**Zscaler Hub の IP 範囲全体への TCP 443 の外向き通信**が必要になります。

- 展開開始：2027年1月末の予定（段階的に、定期メンテナンスの時間帯で実施。開始日は変わる可能性あり）
- 利用者の通信（データプレーン）の扱いは変わらず、通信の中断も想定されていない
- 対象の IP 範囲は、config.zscaler.com で公開されている Zscaler Hub の IP 範囲に含まれている

**運用者がやること**
- Virtual Service Edge の外向き通信をファイアウォールや ACL で制限している場合は、Hub の IP 範囲への TCP 443 が許可されているかを確認し、展開開始までに設定を済ませる

## 4. Agentic SecOps（旧 Avalor）の名称・ドメイン変更

SecOps ポータル（旧 Avalor）が「Zscaler Agentic SecOps」という新しい名称に合わせて更新されます。適用日は**2026年11月15日**です。

- ウェルカムメールや定期レポートの件名、エクスポートファイル名などが新しい名称に変わる
- システムからのメールの送信元が `noreply@riskplatform.zscaler.com` から `noreply@secops.zscaler.com` に変わる
- 新しい地域別ドメインも使えるようになる。既存の認証・API・Webhook のドメインは、当面は新ドメインと並行して使える

**運用者がやること**
メールの受信フィルタや、送信元アドレスでの振り分けルールを設定している場合は、新しい送信元アドレスを追加しておきます。

## 5. その他の情報

### 米国の一部拠点での性能低下（解消済み）

11/4〜11/5 に、ダラス・マイアミ・アトランタ（のちにロサンゼルスも追加）経由で ZIA・ZPA を使う一部の利用者に、性能低下が発生しました。原因は、Zscaler が使っている通信事業者のネットワーク障害による輻輳とパケットロスで、11/5 20:14 UTC に解消が報告されています。
障害中に別のDCへ切り替えた組織は、元の構成に戻すかどうかを確認しておきましょう。

### Linux カーネルの脆弱性（CVE-2026-98432）

Linux カーネルの脆弱性について、Zscaler は次のように説明しています。
- Zscaler OS（ZSOS）を使うクラウド基盤や配布ソフトウェアには影響しない
- Zscaler が管理する Linux ベースのシステムは、修正済みか修正中

一方で、App Connector など**利用者側で OS を管理するコンポーネント**については、OS とパッケージを最新に保つよう推奨しています。自社で管理しているコンポーネントの OS の更新状況を確認しておきましょう。

### データセンターの拡張

- **サンパウロIV**：IP 範囲 `137.31.220.0/23` が追加されます。2027年1月1日以降に有効になります。追加料金が必要な地域DCの拡張です
- **ホノルルI（HNL1）**：private.zscaler.com で ZPA の Public Service Edge ノードが追加されました（11/6 完了）

外向き通信を IP で制限している場合は、config.zscaler.com で公開されている最新の IP 範囲を反映しておきます。

### リリースノートの更新

ZIA・ZPA・ZDX の「Release Upgrade Summary (2026)」が更新されました。デプロイ日として、ZIA に 11/4・11/6、ZPA に 11/2・11/5・11/6 が追加されています。
ZIA のページには、Adaptive Access プロファイルを取得する API、Slack チャットでの DLP インシデントの転送、Azure 連携や Security・UEBA アラート関連の API の追加などが掲載されています。ただし、各項目がどのデプロイ日・どのクラウドに当たるかは、公式ページでクラウドと日付を選んで確認してください。

また、各リリースノートページには、Help Portal のナビゲーション改善に伴い、記事内のメニューの場所が一時的に実際の画面と合わない場合がある、という案内が表示されています。

## まとめ

- 日本の拠点では、**11/19 0:00〜4:00 の OSA1 メンテナンス**に備えて、夜間処理と問い合わせ対応を確認する
- Authentication Service を使うテナントは、**Client Connector の更新が一斉配信になる**前提で、配信の計画を見直す
- Virtual Service Edge を使う組織は、**2027年1月末までに Hub IP 範囲への TCP 443** を許可しておく

詳細や最新の状況は、必ず [Zscaler Trust](https://trust.zscaler.com/) と [Zscaler Help](https://help.zscaler.com/) の公式情報で確認してください。
