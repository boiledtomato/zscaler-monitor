11月13日〜19日に公開された ZPA（Zscaler Private Access）の変更は**4件**でした。
いちばん大きいのは、**VPN（for Legacy Apps）の BGP 設定**の強化です。**集約ルート（Summary Routes）**に対応し、大きなアドレス空間を持つ組織でも、ルートをまとめて扱えるようになりました（限定提供）。あわせて、**App Connector 26.59.2** と **Private Service Edge 26.59.1** の配信も始まっています。

## VPN（for Legacy Apps）の BGP 強化：集約ルートに対応

### 何が変わったか

VPN（for Legacy Apps）で、**BGP のルーティングの選択肢**が増えました。

- **集約ルート（Summary Routes）**に対応
- BGP を有効にしたまま、**ローカルのネットワークセグメントを広告**できる

リリースノートは、ネットワークの導入を簡単にし、ルーティングの柔軟性を高めるもので、とくに**大きなアドレス空間を持つ組織**に向けた強化だとしています。区分は**限定提供**です。

### どんな機能か

**VPN（for Legacy Apps）**は、先週の記事で紹介したとおり、従来型のアプリ向けに、ネットワーク単位で接続するための ZPA の機能です。この機能では **Network Connector** というコンポーネントが使われ、BGP の相手（ピア）とルートをやり取りします。

**BGP**（Border Gateway Protocol）は、ルーター同士が「このネットワークへはこちらから行ける」という経路の情報（ルート）を交換する仕組みです。**集約ルート**は、複数の細かいネットワークを、1つの大きなアドレスのまとまり（例：10.10.0.0/16）で表したルートです（一般的な説明です）。

公式ドキュメント「About Summary Routes」によると、集約ルートを使うと、Network Connector が BGP の相手（ピア）から**まとめたルート**を受け取れるようになり、次の利点があります。

- 広告する個別のルートの数を減らし、ルーティングテーブルの管理を簡単にできる
- 集約ルートの範囲の中であれば、新しいアプリを追加しやすい
- ネットワークを1つずつ設定する必要がなくなり、大きなアドレス空間でも扱いやすい
- 個別のホストのルートより集約ルートの広告を好む、社内のルーティング方針に合わせられる

管理画面では **Private Access > VPN (for Legacy Apps) > Summary Routes** で設定し、集約ルート（CIDR 表記）と、それに含まれる LAN ネットワークを確認できます。

### 対象となる人・設定

- **VPN（for Legacy Apps）**を使い、拠点の Network Connector で **BGP** を有効にしている（または検討している）組織
- とくに、社内のネットワークが多く、ルートの数が増えて管理が大変になっている組織
- 区分は**限定提供**のため、すべてのテナントで使えるとは限らない

### 運用者がやること

- [ ] 集約ルートを使う前に、アプリが Network Segment ごとにどう定義されているかを整理する（公式も、設定前にアプリの定義と Network Segment の構成を考えるよう勧めている）
- [ ] 集約ルートの範囲に、ZPA に通したくないネットワークが含まれないか確認する
- [ ] 使いたい場合は、限定提供の対象になっているか、Zscaler の担当者に確認する

## App Connector 26.59.2・Private Service Edge 26.59.1

### 何が変わったか

**App Connector 26.59.2** と **Private Service Edge 26.59.1** の配信が、11月19日に始まりました。リリースノートの内容は「不具合の修正、最適化、バージョンの強化」で、個別の変更点は書かれていません。

### どんな機能か：自動更新のしくみ

公式ドキュメント「Understanding Software Updates in Private Access」によると、App Connector などのソフトウェアは、**グループごとに決めた曜日と時刻**に自動で更新されます。

- 新しいバージョンが出ると、グループの中から**1台ずつ**選ばれて更新される
- 更新中の台は再起動して一時的に使えなくなり、新しい接続は**同じグループのほかの台**へ回される
- 更新は指定時刻から**4時間の枠**の中で行われ、終わらなかった台は次回の定期更新で再試行される
- バージョン 24.650.4 以降は、最初の接続時にもバージョンの確認と自動更新が行われる

なお、**ホスト OS の更新は利用者の責任**です。Zscaler が更新するのは App Connector などのソフトウェアだけです。

### 対象となる人・設定

App Connector・Private Service Edge を使っているすべての組織。グループの更新スケジュールに沿って、順次更新されます。

### 運用者がやること

- [ ] グループに**2台以上**の App Connector があるか確認する（1台だけだと、更新中はそのグループ経由のアプリに新しく接続できない）
- [ ] 更新の曜日と時刻が、業務の少ない時間帯になっているか確認する
- [ ] 更新後、管理画面の Software Update の列で「Success」になっているか確認する
- [ ] 11月18日の記事で取り上げた Java の脆弱性のように、ホスト OS やほかのソフトウェアの更新は自分で行う

## 分離プロファイルのカナダリージョンをモントリオールに

ZPA の分離プロファイルで選べる「カナダ」リージョンが、**モントリオール**に更新されました。11月21日の記事で紹介した ZIA の変更と同じ内容です。
ZPA の分離プロファイルでも、Regions タブで**2つ以上のリージョン**を選びます。カナダを選んでいて、データを処理する場所に社内の決まりがある組織は、モントリオールで問題がないか確認しましょう。選んでいない組織は、何もする必要はありません。

## まとめ

- VPN（for Legacy Apps）の BGP で、集約ルートと、BGP 有効時のローカルネットワークの広告に対応（限定提供）。大きなアドレス空間でルートをまとめられる
- App Connector 26.59.2・Private Service Edge 26.59.1 の配信開始。グループごとの時刻から4時間の枠で1台ずつ更新される。冗長構成と更新時刻を確認したい
- 分離プロファイルのカナダリージョンは、ZIA と同じくモントリオールに
