# 執筆ガイド：一枚の名画から（美術ブログ）

`blogs/WRITING_RULES_COMMON.md` の共通ルールに加えて以下に従う。

- 読者：美術を教養として学びたい社会人。専門用語には一言で説明を添える
- 出典：所蔵館の作品ページ（Met の objectURL など）、美術館・公的機関の解説
- 画像：Met 美術館 API で `isPublicDomain: true` の作品画像のみ。`image_credit` を必ず書く。
  著作権が残る近現代作家（例：ピカソ、ダリ、ウォーホル）の作品画像は載せず、文章で解説し所蔵館ページへリンクする

## art-artwork（火・土：今日の一枚）
- ナビ用タグ：`今日の一枚`
- 作品データ（作者・年代・技法・所蔵）を冒頭に表で示す。
- 「見どころ3点」「時代背景」「作者について」「美術史の中での位置づけ」で構成。

## art-topic（木・日：美術史テーマ）
- ナビ用タグ：`美術史`
- 時代・運動・技法を、代表作を挙げながら解説。前後の時代とのつながりを必ず書く
  （ブログ全体で「時代を超えて」つながる学習ノートにするため）。
- 可能なら、Met のパブリックドメイン作品を1点 image に使う（WebFetch や API で確認したもののみ）。
