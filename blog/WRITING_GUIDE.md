# 記事執筆ガイド（自動生成用）

このファイルは、Claude（スケジュール実行のセッション、または `scripts/generate_post.py`）が
記事を書くときに必ず従うルールです。人間が読んでも役立つ記事であることが収益化の大前提です。

## 1. 出力形式

`blog/content/posts/YYYY-MM-DD-<slug>.md` に、次のフロントマター付き Markdown を1本書く。

```markdown
---
title: "記事タイトル（32文字前後、検索されそうな語を前に）"
date: 2026-11-03
category: zscaler        # zscaler または art
tags: [ZIA, SSLインスペクション]
summary: "検索結果に出る120文字前後の要約"
topic_id: zt-ssl-inspection   # topics.json の id。ダイジェスト記事は digest-YYYY-MM-DD、作品記事は met-<objectID>
image: "https://images.metmuseum.org/..."   # 任意。パブリックドメイン画像のみ
image_credit: "The Metropolitan Museum of Art, Public Domain (CC0)"  # image がある場合は必須
sources:
  - "https://help.zscaler.com/..."
learning:
  - "この記事で押さえるべきポイント1"
  - "ポイント2"
  - "ポイント3"
quiz:
  - q: "確認問題1"
    a: "答えと短い解説"
  - q: "確認問題2"
    a: "答えと短い解説"
---

本文（Markdown）
```

## 2. 本文の構成

1. **導入**（2〜3文）：誰の、どんな疑問に答える記事か
2. **本題**：`##` 見出しで3〜5セクション。表・箇条書きを適度に使う
3. **まとめ**：3行程度
4. 学習ポイントと確認クイズはフロントマターに書く（本文に重複させない。サイト側で自動表示される）

分量の目安：本文 2,500〜4,000 文字。

## 3. 品質ルール（重要）

- **事実と推測を分ける。** 製品仕様・数値・日付・作品の制作年などは、提供された資料
  （`scripts/blog_sources.py` の出力）か、広く確立した知識に限る。確信が持てない細部は書かないか、
  「公式ドキュメントで要確認」と明記する。
- **出典を必ず `sources` に入れる。** Zscaler 記事は help.zscaler.com / trust.zscaler.com /
  zscaler.com の該当URL、美術記事は所蔵館のページなど。
- **公式文書の丸写しをしない。** 自分の言葉で要約・解説し、引用は短く「」で示す。
- **Zscaler 社の公式ブログ・関係者を装わない。** 「個人の学習ノート」の立場で書く。
  ロゴや公式画像は使わない。
- **画像はパブリックドメイン（CC0）のみ。** Met 美術館 API で `isPublicDomain: true` の作品画像を使い、
  `image_credit` を必ず書く。著作権が残る近現代作家（例：ピカソ、ウォーホル）の作品画像は載せず、
  文章で解説し所蔵館ページへリンクする。
- **同じ topic_id の記事を二度書かない。** `python3 scripts/blog_sources.py today` が未使用のテーマを返す。
- 誇張した煽り（「絶対」「最強」）や、根拠のない比較はしない。

## 4. 記事タイプ別のポイント

### zscaler-digest（週次アップデートまとめ）
- 監視ツールが検出した直近7日の変更（ZIA / ZPA / ZDX / trust）を、
  「何が変わったか → 誰に影響するか → 運用者がやること」の順で整理する。
- trust.zscaler.com のメンテ・障害情報は、データセンター名と影響範囲を表にまとめる。
- 変化が少ない週は、変更点＋関連する基礎知識の解説で記事を成立させる。

### zscaler-topic（基礎・設計解説）
- 初〜中級のネットワーク/セキュリティ担当者向け。仕組み → 設計時の判断ポイント → よくある落とし穴。

### art-artwork（今日の一枚）
- 作品データ（作者・年代・技法・所蔵）を冒頭に表で示す。
- 「見どころ3点」「時代背景」「作者について」「同時代・後世への影響」で構成。

### art-topic（美術史テーマ）
- 時代・運動・技法を、代表作を挙げながら解説。前後の時代とのつながりを必ず書く
  （サイト全体で「時代を超えて」つながる学習ノートにするため）。
